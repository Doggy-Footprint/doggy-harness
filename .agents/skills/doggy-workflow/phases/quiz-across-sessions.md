**Across sessions.** The questions live in the spec so that the session that closes the run uses the questions written before the work began, whichever session wrote them. A later session reads them with the spec and so cannot answer them unseen. In the completion check (Quiz, printed by `close`), it therefore states for each answer the code location or run it cites; a question it cannot answer from a citation counts as a difference to resolve, not a match. A held decision's step adds its questions in the amendment that opens the step, before that step's work, with `built by` naming the step.
