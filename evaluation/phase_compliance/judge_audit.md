# LLM-judge review of the phase-compliance rubric (pilot-A-1 evidence)

Written against the scripts as of the pilot (see `runs.md`); file:line references may have moved since. None of the fixes below is applied yet.

Pilot: judge repeats agree 57/67 (85%), Cohen's kappa 0.76; same transcript judged twice moved verify 83%→43%, close 50%→20%, amend 100%→67%, approve 50%→42%. 222/225 evidence quotes verbatim.

1. Judge noise > what few runs show. aggregate.py:53 uses one repeat; aggregate.py:74-83 raw agreement. Fix: 3 repeats, per-item majority (no majority → unobservable); report kappa and flipped items; compare item by item with the run-to-run flip count as baseline.
2. All-parts-required items almost always fail (judge.md:5 one violation fails; voice group fails if any message fails, rubric_j.json:72). Many-part items: B5 (~8 parts), A2 (~10), I3 (~12), also A3, I2, E4, R5, R6, X3. Pilot: all 5 voice items, 6/7 understanding, 6/7 spec fail in both repeats. Fix: one yes/no sub-check per required part and per message; fraction met in `measure`, used as score.
3. Skipped steps become "unobservable" and leave the denominator (judge.md:11, aggregate.py:65). X1 (completion check absent → should be fail), R12 (package.json not given; `pnpm check` = lint && test && typecheck && check:skill-assets → pass), M1 (judge.py:83 cuts commands at 400 chars). Fix: allow "fail by absence" citing where the action should have been; script R12 and M1; remove the 400-char cut; show unobservable count next to each rate.
4. Unclear premises cause most flips: na/unobservable vs verdict on A14 (did user answer the invitation), D6 (did a fact answer settle a decision), A9 (did a quiz answer differ), X6 (real work), E8 (mutations counted only when run and detected); scope disagreements on C3 (retry = subagent redispatch or shell retries too), E4 (second verifier prompt needs full map?), E5 (advisories need ids?), X5 (which questions already asked), A8. Skill terms ("significant", "engineer call", "valid", "contract-only") undefined for the judge while judge.md:10 forbids importing workflow rules. Picks file (expected quiz answers) not given → A8/A9 graded without expected answers. Fix: short judge glossary from rule_inventory.md:41,:130,:131; scripts decide `na` where events settle it (verifier dispatched, mutations run, Test command failed, redispatch, run completed, user-decision count from markers); give picks file to approval and close groups; define "retry" and "differs".
5. One event counted several times: hidden-intent mishandling fails A8, A9, G-H1, G-P; CQ reuse fails A15 and X5; G-P duplicates D5, A10, G-H1, F3. Fix: one owning item per event; drop G-P (report probe outcomes as a separate table); drop A15 or X5's "not yet asked" part.
6. Contradicting items: V1 (no function names) fails on `containsUnknownType` that G-B3 requires; V4 (no thresholds/test techniques) fails on the closing sentence A3 requires; R11 failed on template header placeholders. Fix: scope V1/V4 to exclude what other items require (may be a skill-level conflict → ask user).
7. Agent's own claims taken as evidence (authority bias): repeat 1 passed A8 / na A9 adopting "you already corrected yourself"; D5 and E5 evidence quotes agent claims ("추천은 넣지 않았습니다", "막는 지적은 없고"). Fix: judge.md rule that the agent's statements about its own compliance are not evidence; give the dispatch group the subagent reports (Agent tool results).
8. No human calibration (needs user labels; out of scope unless the user agrees).
9. One model family everywhere (same for all arms; a blinding check optional).
10. Smaller: log message length per run; schema asks verdict before evidence/rationale (judge.py:27-34) → put rationale and evidence first; add automatic quote substring check; bootstrap CI meaningless at 1–3 runs → report raw per-run values; compare runs only where the same probes fired.
