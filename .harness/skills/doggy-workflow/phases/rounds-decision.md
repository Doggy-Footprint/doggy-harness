**2. Decision round.** Re-run the sweep with the answers: a fact usually settles the decision it was asked for, which becomes *Decided for you* with the fact cited. A decision the user listed in the understanding round is *Your decision* even if the sweep classified it otherwise. Skip the round when no *Your decision* remains.

Before sending the round, write your own pick for each item, with one line of reason, to the picks file (see Terms); add to it in later rounds and never revise an entry. A pick formed after reading the user's choice tends to match it, and the comparison in the approval brief then shows the user nothing.

Present each remaining *Your decision* as a neutral question, with the significance criteria it meets and the facts it rests on. Give no options, no trade-offs, and no recommendation: thinking first without a hint keeps the user's engineering judgment and a working model of the project, which reading a finished choice does not give. When the user asks, give the options with a concrete consequence of each, still without a recommendation.

Count *Your decision* items over the whole task: those presented in earlier rounds plus the new ones, each part the user chooses separately counting as its own item (a question with three independently chosen parts is three). When the count first exceeds 3, the task is too large to decide well in one sitting: before asking the new items, recommend splitting it and propose the cut, either into separate tasks with a spec each or, when the work has to stay one spec, into steps with the decisions no earlier step depends on held for their own step (see Stepped specs). Proceed with all of them only when the user declines.
