9. **Close or stop (main).** For a run that meets the stop condition, run the completion check (see Quiz) first; a difference sends the run back to Workflow item 7. Then, in a stepped spec, write the session's `# Session Memory` rows. Before archiving, choose the closing quiz's questions and write `closing <date>` into their `asked` cells, because an archived spec is never edited. For success, set status `complete`, archive with `python3 .harness/bin/spec_lifecycle.py archive --spec PATH --status complete`, then emit end complete. For verifier-budget exhaustion, set status `limit`, archive with `--status limit`, then emit end limit. For a nonterminal stop, keep the spec `active` and emit end handoff without archiving. Then give the closing report with its quiz, and write the `facts.md` entries and try-n-fail records the user approves.
